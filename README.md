# 🪟 Guía de Instalación de Windows 11 Home 64-Bit

Guía web interactiva, moderna y detallada paso a paso para instalar **Windows 11 Home 64-Bit** desde cero en portátiles sin sistema operativo (FreeDOS / No OS / Linux).

---

## 🚀 Características
- **100% Oficial:** Enlaces y capturas reales de descarga de la ISO desde los servidores de Microsoft.
- **Preparación de USB con Rufus:** Configuración paso a paso en formato GPT / UEFI.
- **Menú de Arranque (Boot Menu):** Tabla interactiva con atajos de teclado para las principales marcas de portátiles (ASUS, HP, Lenovo, Dell, Acer, MSI, etc.).
- **Instalación Pantalla a Pantalla:** Explicación clara de particiones, selección de edición y primer reinicio.
- **Configuración Inicial:** Atajos para continuar sin cuenta en línea o sin Wi-Fi (`oobe\bypassnro`).
- **Diseño Web Moderno:** Responsive, modo oscuro/claro, visor ampliado de imágenes (Lightbox) y lista de requisitos interactiva.

---

## 🛠️ Tecnologías
- HTML5 Semántico
- CSS3 Vanilla (Custom Properties, Glassmorphism, Flexbox, CSS Grid)
- JavaScript Vanilla (Interactividad, LocalStorage, ScrollSpy, Lightbox)

---

## 📄 Uso
Simplemente abre el archivo `index.html` en cualquier navegador web moderno o alójalo en GitHub Pages.
